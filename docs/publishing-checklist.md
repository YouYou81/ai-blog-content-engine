# Publishing Checklist

Use this checklist before sending an article to WordPress, Ghost, Notion, or another CMS.

## Keyword Pool

- Keyword row has owner, intent, priority, and target platform.
- Slug is final.
- Status is ready for draft creation.
- Existing content has been checked for overlap.

## Metadata

- Title includes the primary keyword naturally.
- Title is clear and click-worthy.
- Meta Description summarizes the value.
- Keywords include primary keyword and related long-tail keywords.
- Cover Image Alt is descriptive.

## Article Structure

- TDK is separate from the article body.
- TL;DR uses short bullet points.
- Introduction gives the main answer early.
- Body includes examples, process, or decision criteria.
- Comparison table appears only when helpful.
- Conclusion includes the intended CTA.
- FAQ has 3-5 plain questions and answers.
- FAQ is the final article section.

## SEO Quality

- Readability score passes the team threshold.
- Keyword density is natural.
- Search intent is fully covered.
- E-E-A-T signals are visible.
- Article is not duplicative of existing content.
- No keyword cannibalization risk is unresolved.
- Internal links point to relevant pages.
- External links point to authoritative sources.

## Cover Image

- Image is 16:9.
- Image matches brand style.
- Filename uses the slug.
- Alt text is ready.
- Image has no unintended text artifacts.

## Publishing

- Target platform is selected.
- Draft is created before final publish.
- Cover image is attached.
- Canonical URL is correct when required.
- Published or draft URL is written back to Google Sheet.
- Status is updated.
- If a backend MCP is used, the config contains only generic names and environment-variable placeholders.

## Post-Publish Tracking

- URL is included in the GSC tracking job.
- 7-day and 28-day performance checks are scheduled.
- Template score will be updated after data collection.
